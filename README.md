# レジュメ用テンプレート

研究室のレジュメ（ゼミ資料）を作成するためのLaTeXテンプレートです．
従来のテンプレートをベースに，uplatex対応や便利な設定を追加しています．

> **このリポジトリは基本的にレジュメ用（`style/resume`）のテンプレートです．**
> 卒論用のスタイル（`style/thesis`）も同梱していますが，こちらはあくまで**参考程度**のものです．卒論の体裁は研究室ごとに指導教員の指示があるはずなので，まずはそちらに従ってください．このスタイルの利用を強要するものではありません．参考になりそうなら自由に使ったり，必要な部分だけ取り入れたりしてください．

## このテンプレートでできること

- **レジュメ**（A4・2段組）のきれいなPDFを作れます．レイアウトはテンプレートにおまかせで，中身を書くことに集中できます
- 下書き中は透かし（DRAFT表示）と日付を自動で入れられるので，版の取り違えを防げます
- 卒論用のスタイルと，LaTeXの書き方見本（図・表・数式・ソースコードなど）も入っています
- コンパイル（`.tex`ファイルからPDFを作る作業）の環境は4種類から選べます．**LaTeXをはじめて使う人はOverleaf（方法1）を選べばOKです**

## 執筆環境の選び方

| 環境 | 向いている人 | 備考 |
|---|---|---|
| [方法1:Overleaf](#方法1overleafで書くいちばん簡単おすすめ) | **まずはこれ**．ブラウザだけで完結，インストール不要 | 無料枠にはコンパイル時間の制限あり |
| [方法2:ローカル環境](#方法2ローカル環境で書くmactex) | 好きなエディタで書きたい，オフラインで書きたい | MacTeXのインストールが必要（約5GB） |
| [方法3:Docker](#方法3dockerで書く) | PCの環境を汚したくない，Dockerを使ったことがある | LaTeX本体のインストール不要．イメージ約8GB |
| [方法4:Appleコンテナ](#方法4appleコンテナで書く) | Docker Desktopを入れたくない | macOS 26以降・Apple Silicon限定（実験的） |

どれを選んでも同じPDFが作れます．迷ったらOverleafで始めて，慣れてきたら他の方法に移るのがおすすめです．

## 準備:テンプレートを手に入れる

まずこのテンプレート一式を自分のPCにダウンロードします．

1. このリポジトリのページ上部にある緑色の **`Code`** ボタンをクリック
2. **`Download ZIP`** を選んでダウンロード
3. ダウンロードしたZIPファイルをダブルクリックして展開（解凍）する
4. 展開してできたフォルダ（`k-tex-template-main` など）を，わかりやすい場所（書類フォルダなど）に移動しておく

> Gitを使ったことがある人は `git clone` でも構いません．
> Overleaf（方法1）を使う場合は，展開せずZIPファイルのまま使うので手順3・4は不要です．

## 方法1:Overleafで書く（いちばん簡単・おすすめ）

[Overleaf](https://www.overleaf.com/)は，ブラウザ上でLaTeXを書いてPDFを作れる無料のWebサービスです．
自分のPCに何もインストールしなくてよいので，はじめての人はここから始めましょう．

### 手順（初回のセットアップ）

1. [Overleaf](https://www.overleaf.com/)でアカウントを作成してログインする
2. [準備](#準備テンプレートを手に入れる)でダウンロードした**ZIPファイル**を用意する（展開しなくてよい）
3. Overleafの画面左上の **`新規プロジェクト`**（New Project）→ **`プロジェクトのアップロード`**（Upload Project）を選び，ZIPファイルをアップロードする
4. プロジェクトが開いたら，画面**`メニュー`**（Menu）ボタンを押し，**`コンパイラ`**（Compiler）を **`LaTeX`** に変更する（最初は`pdfLaTeX`になっていますが，このテンプレートは日本語用の`LaTeX`設定で動きます）
5. 同じメニューの**`メインドキュメント`**（Main document）が **`main.tex`** になっていることを確認する
6. **`再コンパイル`**（Recompile）ボタンを押すと，右側にPDFが表示されます

これで準備完了です．あとは左側のエディタで`.tex`ファイルを編集し，`再コンパイル`を押すたびにPDFが更新されます．
次は[レジュメを書き始める](#レジュメを書き始める)へ進んでください．

> **無料枠の注意:** 無料プランはコンパイル時間に制限があり，大きな画像をたくさん使ったりページ数が増えたりするとタイムアウトすることがあります（レジュメや一般的な卒論のサイズなら十分使えます）．

## ターミナルの基本（方法2〜4で共通）

方法2〜4は「ターミナル」でコマンドを入力して操作します．使ったことがなくても，次の2つだけ覚えれば大丈夫です．

**ターミナルの開き方（macOS）:**
`アプリケーション` → `ユーティリティ` → `ターミナル.app` を開きます（Spotlight検索（⌘+スペース）で「ターミナル」と入力してもOK）．

**テンプレートのフォルダに移動する:**
このREADMEに出てくるコマンドは，すべて**テンプレートのフォルダの中で**実行します．ターミナルを開いたら，まず次のように移動してください．

```
cd テンプレートを置いた場所/k-tex-template-main
```

> パスを手で入力しなくても，`cd `（半角スペースまで）と打ってから，Finderのフォルダをターミナルの画面にドラッグ&ドロップすると自動で入力されます．
> いま自分がどこにいるかは `pwd`，そのフォルダに何があるかは `ls` で確認できます．`main.tex` や `Makefile` が表示されれば正しい場所にいます．

## 方法2:ローカル環境で書く（MacTeX）

自分のMacにLaTeX一式（MacTeX）をインストールする方法です．
コンパイルが速く，好きなエディタ（VS Codeなど）と組み合わせられます．

### セットアップ（初回だけ）

1. [Homebrew](https://brew.sh/ja/)（Macのパッケージ管理ツール）を入れていない場合は，公式サイトの手順でインストールする
2. ターミナルで次のコマンドを実行してMacTeXをインストールする（約5GBのダウンロードがあるため，学内Wi-Fi等の安定した回線で．数十分かかることがあります）

    ```
    brew install --cask mactex-no-gui
    ```

3. インストールが終わったら，**ターミナルを一度終了して開き直す**（コマンドを認識させるために必要です）
4. 動作確認として次を実行し，バージョンが表示されればセットアップ完了です

    ```
    latexmk --version
    ```

### 使い方（毎回）

[テンプレートのフォルダに移動](#ターミナルの基本方法24で共通)してから，次のコマンドを実行するとPDF（`main.pdf`）ができます．

```
latexmk main.tex
```

`latexmk`はコンパイルに必要な処理（`uplatex`→`dvipdfmx`など複数回の変換）を自動でまとめて実行してくれるコマンドです．設定は同梱の`latexmkrc`に書いてあるので，何も考えずに上のコマンドだけでOKです．
ファイル名を省略して `latexmk` だけでも`main.tex`がコンパイルされます．`make` と入力しても同じことができます．

**便利なオプション:**

```
# コンパイル後にPDFを自動で開く
latexmk -pv main.tex

# 保存するたびに自動で再コンパイル（書きながら確認するのに便利．Ctrl+Cで停止）
latexmk -pvc main.tex        # または make watch
```

自動再コンパイル（`-pvc`）とSyncTeX（エディタとPDFの相互ジャンプ）はローカル環境専用の機能で，Docker・Appleコンテナでは使えません．

**中間ファイルの掃除:**
コンパイルすると`.aux` `.log`などの中間ファイルができます．散らかってきたら次で掃除できます．

```
latexmk -c      # 中間ファイルのみ削除（PDFは残す）．make clean でも同じ
latexmk -C      # PDFも含めて生成物をすべて削除．make distclean でも同じ
```

## 方法3:Dockerで書く

Docker（アプリを「コンテナ」という隔離された箱の中で動かすツール）を使い，LaTeX一式が入った公式イメージ（[texlive/texlive](https://hub.docker.com/r/texlive/texlive)）でコンパイルする方法です．
自分のPCにLaTeXをインストールしないので環境が汚れず，フルセットのイメージなのでパッケージ不足のトラブルも起きません．

### セットアップ（初回だけ）

1. [Docker Desktop](https://www.docker.com/products/docker-desktop/)を公式サイトからダウンロードしてインストールする
2. Docker Desktopを起動する（メニューバーにクジラのアイコンが表示され，安定するまで少し待つ）

### 使い方（毎回）

Docker Desktopが起動している状態で，[テンプレートのフォルダに移動](#ターミナルの基本方法24で共通)してから実行します．

```
make docker
```

**初回だけ**イメージのダウンロード（約2.5GB，展開後約8GB）が入るため数分待ちます．画面が動いていなくても固まったわけではないので安心してください．2回目以降はすぐにコンパイルが始まります．

`make docker`は次のコマンドの省略形です（`make`が使えない環境ではこちらを直接実行してもOK）．

```
docker run --rm -v "$PWD:/workdir" -w /workdir texlive/texlive:latest latexmk main.tex
```

イメージは週次で更新されているので，たまに `docker pull texlive/texlive:latest` で更新するとよいです．

## 方法4:Appleコンテナで書く

macOS 26以降のApple Silicon Macなら，Docker Desktopの代わりにApple公式の[containerコマンド](https://github.com/apple/container)でも方法3と同じイメージでコンパイルできます（比較的新しいツールなので実験的な位置づけです）．

**自分のMacが対応しているか確認:** りんごメニュー → `このMacについて` を開き，「チップ」に **Apple M1/M2/M3/M4** などと表示されていて（＝Apple Silicon），macOSが **26以降**であればOKです．

### セットアップ（初回だけ）

```
# containerコマンドのインストール（Homebrewが必要．方法2の手順1を参照）
brew install container
```

### 使い方（毎回）

```
# コンテナサービスを起動（Macを再起動した後にも一度実行が必要）
container system start

# コンパイル（make apple でも同じ）
make container
```

初回はイメージのダウンロードで数分待ちます．`make container`は次のコマンドの省略形です．

```
container run --rm -v "$PWD:/workdir" -w /workdir texlive/texlive:latest latexmk main.tex
```

メモリ不足でコンパイルに失敗する場合は，上のコマンドに `--memory 2g` を付けて実行してみてください．イメージの更新は `container images pull texlive/texlive:latest` です．

## レジュメを書き始める

環境ができたら，いよいよレジュメを書きます．関係するファイルは次の3つです．

| ファイル | 役割 |
|---|---|
| `main.tex` | コンパイルの起点．設定を書き，本文ファイルを読み込む |
| `resume/example.tex` | 記入例と書き方見本（図・表・数式などの実例集） |
| `resume/your-resume.tex` | **自分のレジュメはここに書く** |

### 手順

1. まず何も変更せずに一度コンパイルして，`main.pdf`（見本のレジュメ）ができることを確認します
2. `resume/your-resume.tex` を開き，`resume/example.tex` を参考にしながら自分の内容を書きます
3. `main.tex` を開き，読み込むファイルを次のように切り替えます（`%`はコメント＝その行を無効にする記号です）

    ```tex
    % \include{resume/example}
    \include{resume/your-resume}
    ```

4. コンパイルしてPDFを確認しながら書き進めます

書き方がわからないもの（図の挿入，表，数式，箇条書きなど）が出てきたら，`resume/example.tex` の中に実例とコードがあるので探してみてください．

### 下書きモード（DRAFT表示）

`main.tex` にある `\ThisIsDraft` の行を有効にしておくと，全ページに「DRAFT」の透かしとビルド日のバージョン情報が入ります．
ゼミで配る下書きに付けておくと，どの版かがひと目でわかって便利です．**提出版・完成版ではこの行を削除（またはコメントアウト）してください．**

### レジュメのスタイルの仕組み（参考）

`main.tex` の冒頭は次のようになっています．2段組（`twocolumn`）のレジュメ用クラスと，`style/resume`スタイルの組み合わせで見た目が決まります．

```tex
\documentclass[a4paper,dvipdfmx,uplatex,twocolumn]{jsarticle}
\usepackage{style/resume}
```

## （参考）卒論を書く

> **注意:** 卒論用スタイル（`style/thesis`）は参考程度の位置づけです．卒論の体裁は研究室ごとに指導教員の指示があるはずなので，まずはそちらに従ってください．このスタイルの利用を強要するものではなく，参考になりそうなら自由に使ったり，必要な部分だけ取り入れたりする形で構いません．

卒業論文は章立ての文書なので，レジュメとは別の `thesis.tex` を起点にします（`jsbook`クラス＋`style/thesis`スタイル）．

```tex
\documentclass[a4paper,dvipdfmx,openany,uplatex,report]{jsbook}
\usepackage{style/thesis}
```

### 基本情報の設定

`thesis.tex` の先頭で表紙に載る情報を設定します．これをもとに `\maketitle` が表紙を自動生成します．

```tex
\thesistype{卒業論文}                              % 論文種別
\title{論文タイトル}
\subtitle{サブタイトル}                            % 不要なら空のまま
\author{X12345 愛工太郎}
\supervisor{指導教員名}
\affiliation{愛知工業大学 情報科学部 情報科学科}
\date{2026年3月}
```

### 本文の書き方

本文は章ごとに `thesis/` 以下の `.tex` ファイルへ `\chapter{}` から記述し，`thesis.tex` から `\include{}` で読み込みます．
`thesis/example/` には，論文の書き方の解説とLaTeX記法サンプルを兼ねた記述例（序論・論文執筆の作法・文章作成のためのLaTeX記法・図表数式コードの記法・結論の5章）が用意されているので参考にしてください．
画像の載せ方（サイズ・回転・トリミング・横並び・回り込み・横向きページ），表（セル結合・幅指定・数値揃え・色付き・ページまたぎ），数式，グラフ（pgfplots），ソースコード，アルゴリズムなど，多くのパターンを実例とソースコード付きで網羅しています．
章番号は`quotchap`パッケージで装飾され，各ページのヘッダーに章・節のタイトル，フッターにページ番号が表示されます．

参考文献は `thesis.tex` 末尾の `thebibliography` 環境に記述します（文献数が多い場合はBibTeXも利用できます）．
下書きモード（`\ThisIsDraft`）もレジュメと同様に使えます．

### 卒論のコンパイル

`thesis.tex` はデフォルトの対象（`main.tex`）ではないため，ファイル名の指定が必要です．

```
latexmk thesis.tex          # ローカルの場合
make TARGET=thesis.tex      # makeを使う場合（docker/containerでも同様）
```

## makeコマンド一覧

よく使う操作は `make` にまとめてあります（`make help` でも一覧を表示できます）．

| コマンド | 説明 |
|---|---|
| `make` | ローカル（MacTeX）でコンパイル |
| `make docker` | Dockerでコンパイル |
| `make container`（`make apple`） | Appleコンテナでコンパイル |
| `make watch` | 保存のたびに自動再コンパイル（ローカル専用．Ctrl+Cで停止） |
| `make clean` | 中間ファイルを削除（PDFは残す） |
| `make distclean` | PDFも含めて生成物をすべて削除 |

どのコマンドも `TARGET=` を付けると対象を切り替えられます（例: `make docker TARGET=thesis.tex`）．

## うまくいかないときは（Q&A）

**Q. コンパイルに失敗した．何を見ればいい?**
ターミナル（またはOverleafのログ）で `!` から始まる行を探してください．そこがエラーの本体です（例: `! Undefined control sequence.` は存在しないコマンドを使っている）．エラーの下に出る `l.42` のような表示は「42行目あたりが原因」という意味です．
原因を直しても失敗が続く場合は，一度 `latexmk -C`（または `make distclean`）で生成物を全部消してからコンパイルし直すと直ることがあります．

**Q. `latexmk: command not found` と言われる（方法2）**
MacTeXのインストール後にターミナルを開き直していないのが典型例です．ターミナルを終了して開き直してください．それでもダメならインストールが完了しているか確認を．

**Q. `make: command not found` と言われる**
コマンドライン開発ツールが入っていません．`xcode-select --install` を実行してインストールしてください（Homebrewを入れる過程で入っていることも多いです）．なお`make`を使わなくても，各方法に書いてある元のコマンドを直接実行すれば同じことができます．

**Q. `Cannot connect to the Docker daemon` のようなエラーが出る（方法3）**
Docker Desktopが起動していません．Docker Desktopアプリを起動し，安定してから再実行してください．

**Q. `container` コマンドがエラーになる（方法4）**
サービスが起動していないのが典型例です．`container system start` を実行してから再実行してください（Macを再起動した後は毎回必要です）．

**Q. 日本語フォントのエラーでPDF生成（dvipdfmx）に失敗する（方法2）**
本テンプレートは和文フォントにTeX Live同梱の原ノ味フォント（`haranoaji`）を使うため，MacTeXが入っていれば追加のフォントインストールは不要のはずです．`latexmk -C` で生成物を削除してから再コンパイルを試してください．

**Q. ローカルでは成功するのに，Overleafやコンテナでだけ失敗する**
`\include{}`や`\includegraphics{}`で指定したファイル名の**大文字小文字**を疑ってください．macOSは大文字小文字の違いを無視しますが，Overleafやコンテナ内のLinuxは区別します（例: `Figures/sample.JPEG` と `figures/sample.jpeg` は別物扱い）．

**Q. Overleafで「コンパイルタイムアウト」になる**
無料枠のコンパイル時間制限に達しています．画像のファイルサイズを小さくする（写真は幅1500px程度で十分），不要な中間生成を減らす，などで軽くなります．それでも厳しい場合はローカルやDockerの利用を検討してください．
